# 🏡 Sitio Web de CASIDH - casidh.com.ar

Este repositorio contiene el código fuente del sitio web oficial de CASIDH, un evento deportivo de descenso en bicicleta.

## 🌐 Descripción

casidh.com.ar es una plataforma digital informativa, accesible y profesional, diseñada para brindar a competidores y público en general, información clara sobre el evento.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 📌 Dominio
El sitio está publicado en:
👉 https://casidh.com.ar
